# CorePilot Web

CorePilot's dark-first strategy marketplace and testnet creator interface for
**Elysium + HyperCore**.

Stack: **React + Vite + TypeScript + Tailwind CSS + wagmi + viem**.

## What it does

- **Landing** — product one-liner, how-it-works (non-custodial, constraints, receipts). No APY, no return promises.
- **Explore** — compact, filtered strategy discovery with explicit provenance and unknown-state labels.
- **Strategy Detail** — rule, market context, strategy bounds, a personal-limits preview, on-chain reads when configured, and labelled attempts. Trader authorization is not implemented; “Use Strategy” cannot submit.
- **My Strategies** — honest empty state until a verified trader authorization source exists; no simulated positions or balances.
- **Activity** — indexed execution attempts with a request/rejection receipt view, not a personal fill ledger.
- **Create Strategy** — four-step wizard (trigger → action & constraints → PILOT bond → review & publish) retaining the existing SDK wallet transactions. Funding threshold and direction remain an authoring preview, not stored contract policy.
- **Execution Monitor** — preserved at `/monitor` as a secondary technical route. API evaluation displays `REQUIRES_POLICY`; local simulation is separate.

The compact wallet control uses the existing injected connector. The `/app` overview remains available as a secondary route.

## Data labelling

Every panel is tagged with its data source:

| Badge | Meaning |
|---|---|
| `LIVE DATA` | Market data sourced from an identified live provider. |
| `TESTNET` | Testnet/API context, not proof of a trade or fill. |
| `SIMULATED` | Locally simulated values generated by the UI. |
| `DEMO DATA` | Fallback data shown because the API is unreachable. |

Simulated data is never presented as live.

The evaluator has no verified stored per-strategy funding policy. Even with configured contract
addresses, the current executor skips live strategies fail-closed. Existing deployed bytecode is
unchanged by repository edits; confirm deployment version and addresses before wallet use.

## Configuration

Copy `.env.example` to `.env`:

```
VITE_API_URL=http://localhost:8001
VITE_ELYSIUM_RPC_URL=https://testnet-rpc.elysium.kinetiq.xyz
VITE_ELYSIUM_CHAIN_ID=99801
VITE_PILOT_TOKEN_ADDRESS=
VITE_STAKING_ADDRESS=
VITE_STRATEGY_REGISTRY_ADDRESS=
VITE_EXECUTION_CONTROLLER_ADDRESS=
VITE_MARKET_DATA_ORACLE_ADDRESS=
VITE_FEE_MODULE_ADDRESS=
VITE_RECEIPT_REGISTRY_ADDRESS=
```

If the API is unreachable the UI degrades to clearly-labelled **DEMO DATA** and
never crashes. If contract addresses are blank, on-chain reads are skipped and
the UI reports that the SDK is unconfigured.
