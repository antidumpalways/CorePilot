# CorePilot Web

The CorePilot dashboard: a dark, trading/infrastructure-style interface for the
**programmable strategy execution layer** for **Elysium + HyperCore**.

Stack: **React + Vite + TypeScript + Tailwind CSS + wagmi + viem**.

## What it does

- **Landing** — product one-liner, how-it-works (non-custodial, constraints, receipts). No APY, no return promises.
- **Strategy Explorer** — strategies with market, creator, PILOT backing, status and execution counts.
- **Strategy Detail** — rules, creator bond, execution capacity, live Hyperliquid market data (mark price + funding) and execution history (accepted + rejected).
- **Create Strategy** — wizard (market → trigger → constraints → PILOT bond → review → sign) using the SDK write methods with a connected wallet.
- **Execution Monitor** — live-ish panel polling the API for mark price / funding and running the executor evaluation (`TRIGGERED` / `IDLE` with a step list).

Plus a wallet connect button (injected connector) and a PILOT faucet action.

## Data labelling

Every panel is tagged with its data source:

| Badge | Meaning |
|---|---|
| `LIVE DATA` | Real market data from the API/oracle (e.g. Hyperliquid). |
| `TESTNET` | On-chain / API data from Elysium testnet. |
| `SIMULATED` | Locally simulated values generated by the UI. |
| `DEMO DATA` | Fallback data shown because the API is unreachable. |

Simulated data is never presented as live.

## Configuration

Copy `.env.example` to `.env`:

```
VITE_API_URL=http://localhost:8001
VITE_ELYSIUM_RPC_URL=https://testnet-rpc.elysium.kinetiq.xyz
VITE_ELYSIUM_CHAIN_ID=99801
VITE_PILOT_TOKEN_ADDRESS=
VITE_STAKING_ADDRESS=
VITE_STRATEGY_REGISTRY_ADDRESS=
VITE_EXECUTION_CONTROLLER_ADDRESS=
VITE_MARKET_DATA_ORACLE_ADDRESS=
VITE_FEE_MODULE_ADDRESS=
VITE_RECEIPT_REGISTRY_ADDRESS=
```

If the API is unreachable the UI degrades to clearly-labelled **DEMO DATA** and
never crashes. If contract addresses are blank, on-chain reads are skipped and
the UI reports that the SDK is unconfigured.

## Scripts

```bash
pnpm --filter @corepilot/web dev        # vite dev server
pnpm --filter @corepilot/web build      # tsc && vite build
pnpm --filter @corepilot/web preview    # preview the production build
pnpm --filter @corepilot/web typecheck  # tsc --noEmit
```
